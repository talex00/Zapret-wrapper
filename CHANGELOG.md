# История изменений

## v0.1.0 — первый MVP

Графическая оболочка для zapret: запускает стратегии без `.bat`-файлов и сама подбирает рабочую.

### Запуск обхода

- Автоопределение бэкенда: сборка flowseal/zapret-discord-youtube или чистый bol-van/zapret2.
- Стратегии берутся из самой папки zapret: `general*.bat` разбираются без их выполнения,
  аргументы передаются `winws.exe` напрямую. Фиксированного списка внутри программы нет.
- Один запрос UAC на всю сессию: приложение сразу перезапускается с правами администратора.
- Относительные пути в аргументах — работает в папках с кириллицей в пути (cygwin-сборка winws
  не понимает абсолютные пути с не-ASCII).
- Перед стартом создаются отсутствующие `list-general-user.txt`, `list-exclude-user.txt`,
  `ipset-exclude-user.txt` — без них winws завершался сразу после запуска.

### Тестирование стратегий

- Двухфазный подбор: быстрый прогон по всем кандидатам, затем полная проверка выживших.
- Пробы проверяют то, чем люди пользуются: TLS-хендшейк с SNI, HTTPS-запрос, QUIC/HTTP3,
  HTTP на порту 80, видео-CDN YouTube, а для Discord — сигналинг голоса и UDP/RTP через STUN.
- По умолчанию проверяются YouTube и Discord; Instagram и Twitch подхватываются, если вписать их в настройках.
- Тестовые домены автоматически дописываются в `list-general-user.txt`, иначе стратегия к ним не применится.
- Одна кнопка на запуск и остановку теста, таблица результатов обновляется по ходу с расшифровкой
  по каждой пробе.

### Диагностика

- Перед запуском снимаются посторонние `winws`/`winws2`: два экземпляра ставят конкурирующие
  фильтры WinDivert, и обход перестаёт работать без единой ошибки в логах.
- Проверка DNS: каждый домен резолвится системным резолвером и через DoH по IP-литералу.
  Если системный DNS отвечает «домена не существует» или ведёт в другую сеть — в журнал пишется
  явное предупреждение, что проблема не в стратегиях.
- Журнал пишется также в файл `%APPDATA%\ZapretWrapper\zapret-wrapper.log`, включая полную
  командную строку запуска и вывод winws.

### Интерфейс

- Страницы: Главная, Стратегии, Тестирование, Логи, Настройки. Светлая/тёмная тема и режим «как в системе».
- Собственный логотип (геральдический лев на щите) — векторный, без замыливания на любом DPI.

### Известные ограничения

- Готового билда в релизе нет — собирать самостоятельно (`dotnet publish`).
- Нет автозапуска и трея, нет установки службой.
- Автоподбор проверен на flowseal-сборке; ветка чистого zapret2 испытана слабее.
