# Zapret Wrapper

<img src="assets/logo.svg" width="96" align="right" alt="логотип" />

Графическая оболочка для zapret на Windows 10/11 x64: запускает стратегии обхода без
`.bat`-файлов и сама подбирает ту, которая работает у вашего провайдера.

## Что это

zapret обходит DPI-блокировки YouTube, Discord и других сервисов, манипулируя TCP/UDP-пакетами.
Проблема в том, что рабочая стратегия у каждого провайдера своя, а выбирать её приходится
перебором десятков `.bat`-файлов вручную, каждый раз проверяя браузером, что именно открылось.

**Zapret Wrapper** — нативное WPF-приложение (C# / .NET 8), которое берёт эту работу на себя:

- Запускает и останавливает `winws.exe` одной кнопкой, с одним запросом UAC на всю сессию.
- Берёт стратегии из самой папки zapret, а не из встроенного списка: `general*.bat` разбираются
  без их выполнения, аргументы уходят `winws.exe` напрямую. Обновили сборку — список обновился сам.
- Подбирает рабочую стратегию тестером, проверяя не «ping прошёл», а то, чем люди реально пользуются.
- Объясняет, когда дело не в стратегиях (подмена DNS, посторонний запущенный `winws`).
- Светлая, тёмная и системная тема.

## Поддерживаемые сборки zapret

Папка с zapret определяется автоматически — указывать тип вручную не нужно:

| Сборка | Статус |
| --- | --- |
| [flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) | основной сценарий, на нём ведётся разработка и проверка |
| [bol-van/zapret2](https://github.com/bol-van/zapret2) | поддерживается, но испытана слабее |

Для flowseal-сборки стратегии читаются из `general*.bat` в корне папки, для zapret2 — из его
конфигов и встроенной матрицы методов. Сам zapret в репозиторий не входит и не скачивается:
скачайте его сами и укажите путь в настройках.

## Установка

1. Скачайте zip из [Releases](https://github.com/talex00/Zapret-wrapper/releases) и распакуйте.
2. Запустите `ZapretWrapper.exe`. Программа запросит права администратора: без них WinDivert
   не может поставить сетевой фильтр.
3. На странице «Настройки» укажите папку со своей сборкой zapret.
4. На странице «Тестирование» нажмите запуск теста и дождитесь победителя, затем включайте обход
   на главной.

Билд из релиза self-contained: .NET ставить не нужно. Он не подписан, поэтому SmartScreen
покажет предупреждение о неизвестном издателе.

## Как работает тестер

Подбор двухфазный: сначала быстрый прогон по всем стратегиям, затем полная проверка выживших —
иначе перебор двух десятков стратегий занимал бы час.

Пробы проверяют не доступность домена вообще, а конкретные сценарии:

- TLS-хендшейк с SNI и HTTPS-запрос — откроется ли сайт.
- Видео-CDN YouTube — без него страница откроется, а видео крутиться не будет.
- QUIC/HTTP3 и HTTP на порту 80 — чтобы было чем оценивать соответствующие методы.
- Голос Discord — отдельно сигналинг (TLS) и медиапоток (UDP/RTP через STUN).

По умолчанию проверяются YouTube и Discord. Instagram и Twitch подхватятся, если вписать их в настройках;
любой другой домен тоже можно добавить. Проверяемые домены автоматически дописываются
в `lists/list-general-user.txt` — иначе стратегия к ним просто не применяется.

## Диагностика

Самые больные случаи — когда обход «запущен», но ничего не работает. Программа проверяет две
типичные причины сама:

- **Посторонний `winws`.** Служба zapret или ручной запуск `.bat` держит свой фильтр WinDivert;
  два экземпляра мешают друг другу без единой ошибки в логах. Такие процессы снимаются перед стартом.
- **Подмена DNS.** Каждый домен резолвится системным резолвером и параллельно через DoH по IP-литералу
  (такой запрос не зависит от системного DNS). Если резолвер роутера отвечает «домена не существует»
  или ведёт в другую сеть, в журнале появляется явная ошибка: перебирать стратегии бессмысленно,
  надо менять DNS. На IPv6-сетях не забудьте переопределить DNS и для IPv6.

Журнал виден в приложении и дублируется в `%APPDATA%\ZapretWrapper\zapret-wrapper.log` — там же полная
командная строка запуска и вывод `winws`. Настройки лежат рядом в `settings.json`.

## Сборка из исходников

Требуется .NET 8 SDK и Windows 10/11 x64.

```powershell
dotnet publish src/ZapretWrapper/ZapretWrapper.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true -o publish
```

Релизы собирает GitHub Actions (`.github/workflows/release.yml`) по пушу тега `v*` или вручную
из вкладки Actions.

## Структура проекта

```

├── src/ZapretWrapper/
│   ├── Views/          # Страницы: Главная, Стратегии, Тестирование, Логи, Настройки

```
